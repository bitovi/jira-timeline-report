Add Report modal — redesign

Companion mockup for spec/023-report-modal. Replaces the plain stack of centered subtle buttons with a searchable, left-aligned list where each row carries a type icon, a type badge, and a secondary metadata line. Same data source (selectableReports()); the only new capability is client-side filtering. Everything below the dashed line depends on new Report fields we do not store yet — see the README.

Report type icons — the full set

One icon + badge color per primaryReportType in src/configuration/reports.ts, including Report of Reports. The picker excludes nested report-of-reports today, but the type still needs an icon for the Saved Reports page and the report-type dropdown, so it's drawn here too. Note: the "Scatter Plot" report is really dots placed along a time axis (not an XY cloud), so its icon is dots on a baseline.
