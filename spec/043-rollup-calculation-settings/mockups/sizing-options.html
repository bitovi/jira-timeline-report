"How much work is an item?" — sidebar layout options

Four ways to lay out the same settings. Each one is interactive. Below each, the result shows the size it gives four example epics, and a plain-English summary of the settings. All four can express the same rules; the question is which is easiest to understand.

A. Main choice + fallbacks

Pick one way to size items, then what to do when that's missing.

How much work is an item?

Size each item by If it has no dates
If it still has no size
The main choice is obvious; fallbacks only appear when they apply.
Easy to add a fourth sizing method later.
Three separate controls to read top to bottom.

B. One dropdown of combinations

Every primary + fallback pair as one choice.

How much work is an item?

Size items by If it still has no size
Compact: two controls.
Seven similar-sounding options; you have to read them all to find the one you want.
Grows multiplicatively with each new sizing method.

C. Ranked list

Turn sources on/off and order them; the first one an item has wins.

How much work is an item?

Use the first of these the item has

    Date span and team time both need dates, so only one of them can be on.

    One control shows the whole decision order at a glance.
    Same mental model as the Dates "parent, then children" setting.
    Reordering is fiddly; the span/team-time exclusivity is a special rule.

    D. Fill-in-the-blank sentence

    The settings read as a sentence you can edit.

    How much work is an item?

    Reads exactly like the rule; no separate summary needed.
    Middle clauses appear and disappear as they become relevant.
    Less familiar in a settings sidebar; long sentences wrap in a narrow column.

    Where this sits in the sidebar

    Whichever layout wins, the Work part of the sidebar would be organized as one question per dimension, in this order (Dates — "When is it?" — stays as today above it):

    1. How much work is an item? — the layouts above (estimate, date span, team time; fallbacks).
    2. How much of it is done? — Dates · Dates, but status wins · Status only.
    3. How do parents and children combine? — per level: Children, then parent · Larger of the two · Children only · Parent only.
    4. How are estimates read? (advanced, collapsed) — Median × confidence or median only; missing confidence = 50% or no estimate.
